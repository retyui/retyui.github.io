Guides

CLI

Analyze and compare bundle reports in the terminal or CI.

Requires react-native-bundle-discovery-cli:

Every command takes a metro-stats.json report. An Rsdoctor report or an esbuild metafile works too.

CommandDescription
analyzeShow recommended optimizations for the bundle
packagesList all packages in the bundle
modulesList the heaviest modules
compareCompare two reports

Run any command with --help to see all options:

analyze

Shows recommended optimizations, each with an estimated saving: duplicates, deprecated, outdated and dev-only packages, React Native issues with known fixes, and more. It's the default command, so the analyze name can be omitted.

OptionValuesDescription
--formatdefault (default), jsonOutput format

packages

Lists all packages in the bundle with their versions, paths and sizes. Every installed copy of a package is listed separately, so duplicates are easy to spot.

OptionValuesDescription
--sortsize (default, desc), name (asc)Sort order
--formatdefault (default), table, jsonOutput format

modules

Lists the heaviest modules of the bundle.

OptionValuesDescription
--limitnumber, default 50Max number of modules to print. 0 prints all
--filtertext or /regexp/flagsKeep only modules whose path matches: plain text (case-insensitive) or a regexp
--sortsize (default, desc), name (asc)Sort order
--formatdefault (default), table, jsonOutput format

compare

Compares two reports: total size, added, removed and changed modules and packages, version changes, new duplicates and new deprecated packages. The Compare tab of the UI shows the same comparison.

OptionValuesDescription
--beforefile, requiredBase report, for example from the main branch
--afterfile, requiredNew report, for example from a pull request
--limitnumber, default 50Max number of items per list. 0 prints all
--formatdefault (default), markdown, jsonOutput format. Use markdown for a PR comment
--fail-on-increase50KB, 0.5MB, 51200, 5%Exit with code 1 if the bundle grows more than the limit
--max-size3MBExit with code 1 if the "after" bundle is bigger than the limit
--fail-onnew-duplicates, new-deprecatedExit with code 1 if new duplicate and/or deprecated packages appear

On GitHub Actions the markdown report is added to the job summary automatically. See Bundle size checks in CI for a full setup.
