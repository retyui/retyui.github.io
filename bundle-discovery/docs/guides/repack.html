Re.Pack

For projects using Re.Pack there are two ways to use react-native-bundle-discovery:

  1. As the BundleDiscoveryPlugin Webpack/Rspack plugin
  2. Or with a JSON report from Rsdoctor

Using an AI coding agent? Point it at the setup-react-native-bundle-discovery skill to install react-native-bundle-discovery automatically.

Rspack/Webpack plugin

BundleDiscoveryPlugin creates a metro-stats.json file that react-native-bundle-discovery uses to analyze your JS bundle.

  1. Install the package:
  1. Register the BundleDiscoveryPlugin plugin:
  1. Build the app with the BUNDLE_ANALYZER environment variable:
  1. After the build, metro-stats.json is in the root of your project. Analyze it:

JSON report from Rsdoctor

If you use Rsdoctor, generate a JSON report that react-native-bundle-discovery can read.

  1. Install the packages:
  1. Register the RsdoctorRspackPlugin plugin:
  1. Build the app with the RSDOCTOR environment variable:
  1. After the build, rsdoctor-data.json is in the root of your project. Analyze it:

Known limitations

rsdoctor-data.json does not include the source code or bundled output code.
